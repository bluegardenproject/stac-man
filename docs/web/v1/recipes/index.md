# Recipes

Multi-step workflows with branch-tree diagrams. Pick whichever scenario looks closest to yours.

- [Split a fat branch](./split-fat-branch) — break one big branch into a reviewable chain.
- [Land the bottom of a stack](./land-bottom-of-stack) — merge bottom-up without cleanup pain.
- [Recover from a bad rebase](./recover-from-bad-rebase) — paused conflicts, undo, escape hatches.
- [Review someone's stack](./review-someones-stack) — pull a teammate's PR chain locally.
- [Absorb fixups](./absorb-fixups) — route loose hunks back into the right ancestor commit.

If a workflow you need isn't here, the [command reference](/v1/commands/) covers each verb in detail.
