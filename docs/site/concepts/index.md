# Concepts

Five short pages covering the mental model `sm` is built on. Read these once and the command surface should make sense in context.

- [Stacks](./stacks) — what a stack is and why dependent PRs.
- [Trunk](./trunk) — auto-detection, override, the role of trunk in every command.
- [Restack](./restack) — what gets rewritten when a parent moves, when the engine pauses, how to resume.
- [Sync](./sync) — pulling latest, pruning merged branches, retargeting survivors.
- [Parent metadata](./parent-metadata) — where stack relationships live and what `sm doctor` validates.

If you only have time for one page, start with [Stacks](./stacks).
